# Livros-API

## Introdução: 
Nesse projeto o objetivo principal do négocio é fazer um facilicitação na busca de livro para quem se interessa por leitura através da api de lifros da google

## Objetivos:
Criação de um front-end<br>
Utilização da biblioteca streamlit<br>
Maior interação com os livros<br>
Utilizar a api da google

## Livros
Os livros são dizitalizadas pela google que disponibiliza seu acesso através de requisições rest com uma chave unica para a api google books 

## Objetivo Final:
Aumentar o interrese por leitura<br>
Maior facilidade de procura para leitores
